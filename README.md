# Galici — Demo

Proyecto minimal para la UI de Galici creada con Vite + React + Tailwind.

Requisitos
- Node.js (>=18) y npm o pnpm.

Instalación

```bash
npm install
```

Ejecutar en desarrollo

```bash
npm run dev
```

Build

```bash
npm run build
npm run preview
```

Notas
- El componente principal está en [src/App.jsx](src/App.jsx).
- Usa `lucide-react` para los iconos y Tailwind para estilos.
